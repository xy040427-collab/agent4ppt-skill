# Ten directions, thirty pages

Each scenario contains three selected pages, not a full-length presentation.

| Scenario | Page roles |
|---|---|
| Cute comic | Story panels, question, garden conclusion |
| Research meeting | Setup, native latency chart, next experiment |
| Technology launch | Reveal, cooling detail, design summary |
| Paper presentation | Method notation, native table, limitations |
| Job introduction | Positioning, project, strengths |
| Club election | Platform, commitments, accountability |
| Business review | Annual indicators, weekly update, native chart |
| Product advertising | Campaign, material detail, closing |
| Policy briefing | Fictional policy, eligibility, schedule |
| Recruitment | Poster, role spotlight, event agenda |

All 30 pages were exported using PowerPoint 16.0 and visually inspected. Text placement was corrected where artwork occupied intended whitespace. Representative copies were edited and saved: a title, chart series values and a table cell. Formulas are editable text notation, not native equation objects.

This evidence does not establish first-pass success rates, independent installation, all twelve style recipes, or all application compatibility. All numerical results are invented examples. No brand assets, official seals or third-party slide templates were used.

RRF method: Cormack, Clarke and Büttcher, SIGIR 2009, https://cormack.uwaterloo.ca/cormacksigir09-rrf.pdf . No paper results, figures or copied prose are reproduced.
