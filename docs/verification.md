## 不应夸大的结论

这些结果证明已测流程能够工作，不证明全题材、所有模型、所有配置的质量完全等价或更强。内置图像工具是真实调用；OpenAI 和 AtlasCloud API 使用本地模拟端点，没有真实账户凭据，不能宣称在线验证完成。

PPT 页面仍是栅格图片。生成式参考编辑不能保证原始图表、车身、人物等细节逐像素一致。没有在 PowerPoint 桌面版打开文件。独立 Artifact 渲染器在输出全部页面后返回了退出码 1，未给出错误文本；随后已独立打开所有 PNG，并完成上述像素对比，因此这里只声称输出文件验证通过，不把该进程描述为正常退出。

## 接口变化

- 旧脚本入口改为一个 `agent4ppt` 命令；不提供旧命令名称的兼容壳。
- JSON 状态文件改为 SQLite；可读 JSON 是快照，不再手工编辑状态。
- 原有成品图片可用 `assemble --images ... --notes ... --out ...` 重新导出，不会伪造新生成记录。
- 缺图会阻止导出，默认不压缩图像；需要压缩时显式设置大小预算。
- 默认使用用户授权决定推进程度，不要求对每一个步骤重复确认。
- 个人配置和风格目录改为 `AGENT4PPT_HOME` / `~/.agent4ppt`；不会自动读取或更改旧目录。

旧项目应先保留备份，再按新 brief 格式创建后续可编辑任务。这一版本以保持核心能力覆盖为目标，尚不能宣称已经证明全量无回归。
