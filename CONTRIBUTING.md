# Feedback and contributions

Report the host, operating system, production mode, expected output, actual behavior and a minimal sanitized reproduction. Explain whether the problem occurs in the exported PPTX, preview or both.

Do not upload private presentations, credentials or unlicensed materials. The public license permits personal noncommercial use of the unmodified tool. Obtain written authorization before modifying the tool or submitting code changes. Read LICENSE. No contribution license agreement or transfer of ownership is implied; agree contribution terms before accepting code.

Maintainers: run `python -m unittest discover -s tests -v`. Separate mock provider tests from live generation evidence. Preserve substantive style guidance and report limitations accurately.
