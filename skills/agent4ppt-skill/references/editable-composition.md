# 可编辑图文制作（试验）

目标是保留整页设计的协调感，同时让标题、正文、数字、表格和必要的图示成为可修改对象。场景、光影和复杂装饰可以保留为完整图片；不承诺图片中每个物体都能单独编辑。按宿主已有能力选择制作工具，不要求安装特定库，也不将任务脚本、字体、素材或渲染器加入 skill。

## 整体设计，分别制作

先确定每页准确文案、承担的结论、图文位置与层级，再决定哪些部分由图片表达。统一字体、配色和视觉语言，按内容变化构图。整页背景、自然留白、独立插画都可采用；不要默认将内容变成卡片网格。

把有助于识别内容的图标、标注和连接关系一并规划，不能在可编辑化时只留下正文。普通图标优先选宿主已有的同一套资源，统一线宽、颜色、视觉大小并保留来源；有明确风格需求时再生成定制插画。为每个小图标单独生图可能增加等待和失败次数。用共同对齐、邻近关系和语义颜色组织图文，不把渐变留白当作唯一融合方式。

用真实文字和实际字体试排，留出修改余量。空间不足时调整区域或结构；不能静默删改内容，也不能无限缩小文字。复杂页面可先看布局草稿或视觉样稿，普通页面不必额外生图。样稿用于设计参考，不通过抠字、切碎图片恢复图层。

生图任务应说明目标区域、比例、主体位置、留白范围及图像职责。可编辑文案不进入图片；需要精确保留的图表、截图和标识直接放入页面。保持主视觉完整，避免把一个协调的场景拆成大量独立小图。新增图片使用宿主可用的图片工具。

生成的留白不一定符合指令。先实际观看素材，再检查与文字的配合；文字试排通过不能替代这一检查。遇到景物侵入文字区域，选择修正素材或局部调整布局，不习惯性用大色块遮盖。核对允许的叠放关系，区分设计上的覆盖和错误遮挡。

## 分工与修改

有授权且宿主支持时，协调者统一内容、素材主题、共用元素及设计版本，再派发独立素材任务。执行者拿到固定提示词、参考图用途、输出要求和版本，只生成指定素材并报告问题，不新增论点、图标体系或页面内容。共享素材只生成一次；并发量按实际后端成功率调整，不承诺按 agent 数量线性加速。

保留对象标识和任务素材。修改时定位已有文字、图表或图片对象；同步修改相关数字、标签和语义颜色，保留未受影响对象。短文本修改通常无需重新生图；内容明显变长时重新检查布局。先支持本工具产生的工程，不声称任意外部 PPT 可无损回写。

活动或步骤改变时，也检查对应图标是否仍然准确。独立图标至少应可替换，不能仅因输入是 SVG 就声称最终文件保留矢量或可拆分路径；检查导出后的资源及兼容预览，必要时使用清晰的透明图片并保留源素材。导入后名称可能丢失，定位修改对象时核对内容、位置和数量，不能猜测对象身份。

## 验收

重新打开最终 PPTX，确认正文确实是原生对象，原图、数字和备注完整；渲染并观察每页，核对留白、文字重叠、字体、裁剪和整体观感。程序核对内容与对象，视觉检查判断配合效果，两者不能互相替代。

原生图表还需检查数据文件与引用，尤其是再次导出后。若宿主丢失内嵌工作簿，应保留真实源文件并恢复关联，或换用能完整保存的制作方式；不能用截图或编造数据掩盖。流程箭头应指向正确对象。对比设计质量时保持内容与信息量一致；新增题材样张只能证明该次制作，不能替代与原版的对比。

连接线在预览器与目标软件中可能走不同路径。有目标软件时用其打开并导出核对，不能只看生成工具的预览。自动折线不稳定时，可用明确路径的原生折线保留编辑能力，同时告知其不再自动跟随节点；不要为固定外观把整张图示转成图片。

以可见内容的中心和边缘安排箭头落点，避免指向透明文本框内的空白；多路汇入同一步骤时，可先汇合再用短箭头指向目标。

试验阶段实际修改代表性文字和一项结构化内容，确认未要求变化的素材与对象保持一致。预览应来自最终文件。明确未测试的软件环境，以及仍以图片形式保留的部分。观感是否达到原整页生图基准，应提供对比由用户判断，不能仅凭文件验证通过宣布等价。
